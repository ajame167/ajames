Web Servers: Evolution of a Core WWW Component

Abstract

A web server is software that receives HTTP and HTTPS requests and delivers web content. Web servers helped transform the World Wide Web from a research project into the global platform we use today.

Key Terms

  • HTTP:Hypertext Transfer Protocol
  • HTTPS:Hypertext Transfer Protocol Secure
  • Apache:Apache HTTP Server
  • Nginx:NGINX Server
  • IIS:Internet Information Service
  • Cloud Computing:On-demand delivery of IT resources over the Internet
